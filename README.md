## 1. Project Overview

The **Frequency Difference Estimator** module computes the Main RO total relative frequency error (ϵ_RO) as a quadratic function of the temperature deviation from 25°C, combined with an aging contribution supplied by the rRO Aging Engine. The result is represented in signed Q1.23 format and drives the downstream Sigma-Delta Modulator.

Final RTL file: `freq_diff_estimator_vC.v`
Final testbench file: `tb_freq_diff_estimator.v`

## 3. How to Simulation

Simulation is performed using **Cadence Xcelium (xrun, version 22.03-s001)** on the lab CAD server (`bahar`).

---

## 3.1 RTL Functional Simulation

First, go into the simulation folder:

```bash
cd scripts
```

Then run:

```bash
source ./simulation/func_sim.tcl
```

This script simulates the following files:

```text
../rtl_sources/freq_diff_estimator_vC.v
../rtl_sources/tb_freq_diff_estimator.v
```

In RTL mode, the testbench runs `1,000,000` constrained-random vectors together with the directed tests.

The run log is saved to:

```text
./logs/vC_rtl.log
```

### Checking the RTL Output

At the end of the simulation, a summary similar to the following should be observed:

```text
Recorded failures           : 0
Maximum numerical difference: 0 LSBs
Maximum equivalent error    : 0.000000 ppm
FINAL RESULT: PASS -- no check exceeded 20 ppm.
```

## 3.2 Zero-Delay Gate-Level Simulation

Run from inside the same `scripts` folder:

```bash
source ./simulation/postsyn_zero_sim.tcl
```

This script activates the following macro:

```text
POSTSYN_SIM
```

and uses the synthesized Version C netlist:

```text
../synthesis/synout_vC/freq_diff_estimator_vC_postsyn.v
```

In post-synthesis mode, the number of constrained-random tests is `1000`. All directed, boundary, saturation, reset, handshake, and cancellation-sensitive tests are also retained; therefore a total of `1097` vectors are checked.

Log:

```text
./logs/vC_postsyn_zero_delay.log
```

## 3.3 SDF-Annotated Gate-Level Simulation

From inside `./scripts`:

```bash
source ./simulation/postsyn_sdf_sim.tcl
```

This run activates both of the following macros:

```text
POSTSYN_SIM
SDF_SIM
```

The following SDF file is back-annotated by the testbench with `MAXIMUM`-type delays:

```text
../synthesis/netlist/freq_diff_estimator_vC_postsyn.sdf
```

In the testbench:

```verilog
$sdf_annotate(
    "../synthesis/netlist/freq_diff_estimator_vC_postsyn.sdf",
    uut_postsyn, , , "MAXIMUM"
);
```

The script also passes the following option to Xcelium:

```text
-timescale 1ns/1ps
```

This option is required to avoid a missing-timescale error in the netlist generated by Genus.

Log:

```text
./logs/vC_postsyn_sdf.log
```

### Checking the SDF GLS Output

First, confirm that there are no file-access, instance-annotation, or SDF-annotation errors. The final summary should then read as follows:

```text
Checked vectors             : 1097
Recorded failures           : 0
Maximum numerical difference: 0 LSBs
Maximum equivalent error    : 0.000000 ppm
FINAL RESULT: PASS -- no check exceeded 20 ppm.
```

In the waveform inspection in SimVision, the transition on `epsilon_RO[23]` was also observed at a distance of `166 ps` from the active clock edge, matching the falling clock-to-Q delay reported by Genus.

## 3.4 Running the Version C Synthesis

To run synthesis, first go into the synthesis folder:

```bash
cd scripts
```

Then launch the Genus environment:

```bash
genus
```

Once the Genus prompt opens, run the final Version C script with the following command:

```tcl
source ./synthesis/syn_scr_fde_vC.tcl
```

So the synthesis execution flow is as follows:

```text
.../scripts] $ genus
genus> source ./synthesis/syn_scr_fde_vC.tcl
```

The `syn_scr_fde_vC.tcl` script performs the following steps:

1. Loads the TSMC180 library in Typical mode
2. Reads the final Version C RTL
3. Elaborates the design and selects `freq_diff_estimator` as the top module
4. Checks for unresolved references
5. Applies the `131.072 kHz` clock with a period of `7629.394531 ns`
6. Runs `syn_generic`
7. Runs `syn_map`
8. Runs `syn_opt`
9. Generates the clocks, timing, area, power, and gates reports
10. Generates the post-synthesis netlist
11. Generates the SDF file

The main outputs are placed in the following paths:

```text
./synthesis/netlist/
./synthesis/netlist/
```

Key files:

```text
./synthesis/netlist/freq_diff_estimator_vC_postsyn.v
./synthesis/netlist/freq_diff_estimator_vC_postsyn.sdf

./synthesis/reports/vC_area.rpt
./synthesis/reports/vC_timing.rpt
./synthesis/reports/vC_power.rpt
./synthesis/reports/vC_gates.rpt
./synthesis/reports/vC_check_design.rpt
```

  - An incorrect quadratic-term scaling constant (327 instead of the correctly rounded 328).
  - Insufficient precision of the reciprocal-constant approximation; upgraded to a higher-precision constant (171,798,692 / 2^50).
- All tests passed successfully, and the RTL was declared ready for Week 3 synthesis.
- The weekly report has been completed

### Week 3 — Synthesis and Timing Closure
- Synthesized the design using Cadence Genus with the TSMC 180 nm typical library.
- Identified the area bottleneck: the quadratic temperature path (original Version A2, area 98,168.719).
- Evaluated and compared four RTL candidates for the quadratic-term implementation:
  - **Version B** (328/2⁸): lowest area but numerical error exceeded the 20 ppm tolerance → rejected.
  - **Version A** (171,798,692/2²⁷): failed 8 rare cancellation-sensitive vectors under the expanded 1,000,000-vector regression (max. difference 2,569 LSBs) → rejected.
  - **Version A2** (43,980,465,111/2³⁵): passed the full regression (max. error 3 LSBs) but had the largest area (98,168.719) and power (47.9266 µW).
  - **Version C** (exact algebraic simplification to the fraction 32/25): zero numerical difference, 28.80% area reduction and 52.82% power reduction relative to Version A2 → **selected as final**.
- Ran gate-level simulation (zero-delay and SDF-annotated) on Version C with 1,097 vectors; both passed with zero failures.
- Confirmed the measured clock-to-Q delay (166 ps) against the static timing analysis result.
- The weekly report has been completed
